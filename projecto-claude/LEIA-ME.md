# Código do projecto claude.ai «Automatações»

Cópia exacta (byte a byte, verificada) dos 130 ficheiros de código que estavam guardados como documentos no projecto claude.ai «Automatações - Não usar para outros fins». Foram para aqui a 27/10/2026, porque o projecto chegou ao limite de tamanho (2 MB).

Os caminhos são os mesmos que tinham no projecto. Os documentos de texto (.md) continuam no projecto.

Daqui em diante, o código novo das sessões fica neste repositório, neste ramo (`arquivo-projecto-claude`), e não no projecto.
